## 2026-08-26 - Memoizing MarketCard in MarketList
**Learning:** In a highly dynamic list like MarketList where markets update continuously (pool sizes change via silent polling/subscriptions), re-rendering the entire list of `MarketCard`s is a huge performance bottleneck. Supabase reconstructs object references, causing default React equality checks to fail.
**Action:** Wrap `MarketCard` in `React.memo` with a custom `areEqual` comparator. Since Supabase objects change references, we must dynamically shallow-compare `market` properties (iterating over `Object.keys`) and deeply compare arrays like `market.options`. We also need to check stable callback references (`prev.onBetPlaced === next.onBetPlaced`) and session equality (`prev.session?.access_token === next.session?.access_token`) to avoid stale closures and UI bugs.
