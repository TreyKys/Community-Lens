## 2024-05-18 - Prevent unnecessary re-renders in list components
**Learning:** Supabase queries dynamically reconstruct object instances, returning entirely new memory references. Mapped list components like MarketList that depend on these objects need strict React.memo implementation with custom deep-equality comparisons (avoiding JSON.stringify due to performance hit). The memory explicitly instructs: "To prevent excessive React re-renders in mapped lists, wrap list items in React.memo with a custom areEqual comparison. Do not hardcode specific property subsets (like id, total_pool) as it risks stale UI bugs; instead, dynamically iterate over Object.keys to compare all fields, applying deep equality to nested arrays."
**Action:** Implement React.memo for the MarketCard component inside MarketList.tsx using a custom areEqual function that shallow-compares all dynamic keys and deeply compares arrays (like market.options).
