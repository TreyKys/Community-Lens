## 2024-05-18 - [Fix React.memo stale closures in MarketList]
**Learning:** Supabase queries dynamically reconstruct object instances. When memoizing list items using `React.memo` and a custom equality check, it is critical to explicitly compare callback functions (like `onBetPlaced`) passed from parents that use hooks like `useCallback`, in addition to a deep comparison of the data objects. If callbacks are omitted from the comparison, the child component will retain a stale closure to the previous version of the callback, which may capture old UI state (like filters).
**Action:** Always include a `prev.callbackName === next.callbackName` check in any custom `areEqual` function used with `React.memo` in this codebase. Furthermore, iterate over object keys to detect changes in nested array objects (like `market.options`) instead of hardcoding top-level property checks.
