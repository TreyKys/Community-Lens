## 2025-07-20 - Memoizing list item cards in React
**Learning:** In a highly interactive list like a betting feed where the top level component regularly refreshes data from the server causing entirely new object references for items in the list, mapping item components without React.memo causes severe performance bottlenecks as every item re-renders whenever the list does. When object references are unstable, using `React.memo` requires providing a custom `areEqual` deep comparison function, otherwise the memoization will completely fail.
**Action:** Always wrap heavy list item components in React.memo with a custom deep comparison function comparing properties like id, total_pool, status and ensure the callbacks passed to them are stabilized using useCallback. Also, importantly, custom hooks inside the parent list must be declared before any early returns (like `if (isLoading) return <Loader />`) to obey the Rules of Hooks.
