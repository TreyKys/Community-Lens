## 2024-10-27 - [MarketList Component React.memo Object Reconstruction Performance Fix]
**Learning:** Supabase queries dynamically reconstruct object instances, returning entirely new memory references for each row on every fetch. When mapping over these results to render components like `MarketCard`, shallow equality checks fail, causing unnecessary re-renders of the entire list. Using `React.memo` with a custom `areEqual` comparator that performs deep array equality checks and iterates over `Object.keys` prevents these re-renders. Additionally, hooks referencing other hooks (like `handleBetPlaced` referencing `fetchMarkets`) must strictly be declared *after* the referenced hook to avoid Temporal Dead Zone (TDZ) `ReferenceError` crashes.
**Action:** When memoizing list components backed by Supabase data, always use a custom `areEqual` comparator with deep property checks, and ensure stable function references are passed as props (e.g., via `useCallback`). Always verify the lexical ordering of hooks to avoid TDZ errors.
