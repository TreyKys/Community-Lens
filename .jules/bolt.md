## 2024-05-24 - [Avoid `JSON.stringify` for Deep Equality Checking in `React.memo`]
**Learning:** Using `JSON.stringify` to perform a deep equality check in a custom `areEqual` function for `React.memo` (or similar comparison functions) is an anti-pattern. While it may seem like a quick way to compare complex objects like those returned by Supabase, `JSON.stringify` is a synchronous, CPU-intensive operation that blocks the main thread. It's particularly problematic in lists where this check happens frequently, causing significant performance degradation and laggy UIs during renders or state updates. Furthermore, it fails on objects with cyclical references or functions.

**Action:** Implement a custom shallow comparison function instead. Iterate through the `Object.keys()` of the props/objects being compared. For most primitive fields, a simple equality check (`===`) suffices. If you know specific fields are arrays (like `market.options`), you can add a localized deep comparison loop for just those nested arrays. This approach is significantly faster, avoids main thread blocking, and handles the dynamic object recreation issue from Supabase queries efficiently. Additionally, ensure callback functions (like `onBetPlaced`) are properly stabilized with `useCallback` when using `React.memo`.
