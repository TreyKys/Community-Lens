## 2024-06-25 - React.memo for Supabase list items
**Learning:** Supabase queries dynamically reconstruct object instances, returning entirely new memory references on every fetch. When mapping these objects to React components in a list (like `MarketList`), default shallow equality checks fail, causing heavy unnecessary re-renders of the entire list whenever a background poll completes or a single item updates.
**Action:** Wrap list items (e.g., `MarketCard`) in `React.memo` with a custom `areEqual` deep comparison function. Explicitly compare stable properties like `id`, `total_pool`, `status`, and deeply compare arrays like `options`. Also ensure callback props like `onBetPlaced` are stabilized using `useCallback` in the parent to prevent stale closures and further re-renders.
